# 8bit-VRAI

| Opcode | Operation | Description |
|:---:|---|---|
| `0` | `ADD` | Adds operand A and operand B. |
| `1` | `ADC` | Adds operand A, operand B, and the carry-in bit. |
| `2` | `AND` | Performs a bitwise AND on the operands. |
| `3` | `OR` | Performs a bitwise OR on the operands. |
| `4` | `NOR` | Performs a bitwise NOR on the operands. |
| `5` | `CMP` | Compares the operands and updates flags without writing a result. |
| `6` | `SBB` | Subtracts operand B and the borrow-in bit from operand A. |
| `7`–`8` | Reserved | tbd |
