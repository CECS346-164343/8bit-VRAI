# 8bit-VRAI

Code	Operation	Purpose
0	ADD	Adds operand A and operand B
1	ADC	Adds operand A, operand B, and carry-in
2	AND	Performs bitwise AND
3	OR	Performs bitwise OR
4	NOR	Performs bitwise NOR
5	CMP	Compares operands and updates flags without writing a result
6	SBB	Subtracts operand B and borrow-in from operand A
7-8	Reserved
